# Sleepee — حزمة تجميع المتطلبات v1.0 (مسودة)

## الحالة
هذه حزمة توثيق بعد انتهاء إرسال المحادثة القديمة. الوثائق الجديدة **مسودات للمراجعة فقط** وليست موافقة على بدء التنفيذ أو تغيير المرجعية أو الكود أو GitHub أو Supabase.

## ترتيب المرجعيات
1. `Sleepee_Single_Source_Of_Truth_v1.0_Portable_Reference.md` — المرجعية التجارية والتقنية الحاكمة؛ لا تعدّل.
2. `Sleepee_Consolidated_Requirements_Review_v1.2.md` ونسخة DOCX — ملحق مراجعة منفصل.
3. `Sleepee_Review_Register_v1.2.xlsx` — السجل السابق، مرفق للحفاظ على التتبع.
4. وثائق `*_DRAFT_AR` و`Sleepee_Operational_Requirements_Register_v1.0_DRAFT.xlsx` — التجميع الجديد للنقاش المسترجع؛ تحتاج مراجعة واعتمادًا.
5. كود ZIP وملفات المصدر — أدلة لفحص التنفيذ، وليست سلطة لتغيير المتطلبات.

## الوثائق الجديدة
- `Sleepee_Operational_Blueprint_v1.0_DRAFT_AR.docx/.md`
- `Manufacturing_Design_v1.0_DRAFT_AR.docx/.md`
- `Customer_Service_Design_v1.0_DRAFT_AR.docx/.md`
- `Sleepee_Operational_Requirements_Register_v1.0_DRAFT.xlsx`

## ما يحتويه سجل Excel
- `البدء`: الملخص والبوابات الحالية.
- `المتطلبات`: 65 بندًا مسترجعًا أو مستمدًا من المرجعية مع مصدر وحالة ودليل قبول.
- `القرارات`: 27 قرارًا/فجوة تحتاج الحسم.
- `اختبارات القبول`: 27 اختبارًا مقترحًا ولم يُدّعَ تنفيذها.
- `أمثلة التصنيع`: أمثلة محددة للبلصات والشاسيه والزمن والتعارضات.
- `المصادر`: فهرس الملفات وحدود استخدامها.

## أهم ضوابط الاستئناف
- لا تغيّر `Sleepee_Single_Source_Of_Truth_v1.0`.
- لا تشغّل schema أو migrations قبل مقارنة قاعدة Supabase الحية والنسخة الاحتياطية والموافقة.
- لا تدمج Phase 09 وPhase 10–18 بمجرد overlay.
- لا تعتبر المقترحات المسترجعة معتمدة نهائيًا حتى مراجعتها وتسجيل القرار.
- لا تعتبر أي اختبار ناجحًا دون دليل فعلي.
- أي تعارض هندسي/زمني/ضماني يظل مسجلًا كما هو ولا يحل بالتخمين.

## التسلسل التالي
1. يراجع المالك المسودات الثلاث وسجل Excel.
2. تُحسم القرارات الحرجة أو توضع علامتها صراحةً كمعطلة لما يعتمد عليها.
3. تُطابق المسودات مع SSoT الأصلية ويصدر Amendment منفصل عند تغيير/توسيع مطلب أصلي.
4. بعد الاعتماد فقط: اختيار مستودع Sleepee الصحيح، فحص الكود وSupabase للقراءة فقط، أخذ النسخ الاحتياطية، ثم خطة تنفيذ تدريجية.
