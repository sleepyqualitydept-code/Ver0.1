# مصفوفة الفجوات — لا تفترض اكتمال ما لم يثبت

هذه المصفوفة جزء من تسليم الحزمة وتمنع الخلط بين إضافة واجهة وبين اكتمال دورة العمل أو اختبارها على قاعدة Supabase.

| المجال | الموجود في الحزمة | ما لم يكتمل / شرط القبول |
|---|---|---|
| مراكز الواجهة | Sidebar يجمع التنقل تحت أربع مساحات رئيسية + التحقق العام | Customer Service وProduction ما زالا يعرضان صفحات داخلية متعددة؛ هذا دمج تجربة تنقل وليس إعادة بناء كاملة لكل شاشة في مركز واحد |
| Quick Production | Wizard لإنشاء أمر، إرساله للمراجعة، اعتماد الأمر عند توفر الدور، إنشاء دفعة، طلب توليد serials ثم الانتقال للطباعة | لا يوجد اعتماد كامل على BOM/Routing داخل عملية الأمر حتى إقرار Lifecycle وربط الجداول ومطابقة المخطط الحي |
| Advanced/Manual Wizard | الخطوات الحالية تغطي Order → Approval → Batch/Serial → handoff للطباعة | لم يُنفذ بعد مسار كامل لتحديد BOM/Routing/Production Version لكل أمر؛ لا تُفترض القيم أو المسارات |
| BOM Builder | إنشاء مسودات ومكونات BOM في جداول مقترحة | يتطلب مراجعة/اعتماد ترحيل الإضافة، واستيرادًا منضبطًا لبيانات الموديلات بعد حل تعارضات المصدر، ودورة اعتماد لم تعتمد بعد |
| Product Engineering | حقول حرة لمواصفات التركيب/النظام/الوجه/قطر السلك، ومراجع مصدر | قاموس Construction Types وأنواع أنظمة التصنيع لم يعتمد نهائيًا؛ يجب الحفاظ على أسماء المصدر |
| Routing | مسودات خطوات على الأقسام الفعلية الخمسة، مع تكرار ترتيب الخطوات وإشارة إلى ماكينة/خط وأزمنة منفصلة | تحديد مسارات كل موديل/خط تشكيل وأزمنة مقاسة ميدانيًا ما زال مطلوبًا. الزمن الإجمالي المصدر لا يُقسم آليًا |
| Production statuses | Wizard يستخدم الحالات المتاحة في APIs الحالية | `Partially Completed` موجود في المرجع الأصلي ولا يظهر ضمن نوع/قيد الحالة الذي تمت مراجعته؛ يحتاج مقارنة واعتماد migration، وليس تعديلًا منفردًا للكود |
| مراكز الطباعة | Queue/Jobs/Categories الحالية وPresets إضافية للأحجام | Zebra Browser Print SDK وrenderer/ZPL معتمد غير مدمجين/غير مختبرين؛ التنفيذ يرفض النجاح الوهمي ولا يسجل printed |
| Label Designer | محرر القوالب الموجود، مع 100×50 و100×80 و100×100 وأبعاد مخصصة | لا يزال اعتماد التصميم النهائي، وإدارة الأصول من Supabase Storage، وsafe-area/actual-scale hardware proof، وQR payload policies مطلوبًا |
| Customer Experience | Workspace واحد في القائمة للتنقل بين العملاء/الضمان/الخدمة/الاستبدال | دمج الشاشات والتسلسل الزمني الموحد، ودورة compensation، ونقل الملكية، ورفع مرفقات العميل تحتاج مخطط وقواعد واعتمادًا |
| Compensation | موثق في التصاميم كمطلب مسترجع | لا يوجد تنفيذ تشغيلي متحقق أو قواعد سياسة/اعتماد مكتملة؛ لا تنشأ وحدة محاسبية |
| Public verification | العرض العام المصحح من ناحية تسمية التواريخ وبيانات منتج/ضمان أساسية | أي بحث بهاتف/فاتورة/هوية أو رفع صور يحتاج مصادقة وحدود خصوصية وRPC معتمد؛ لا يعرض PII للعامة |
| Analytics/Data export | مركز التقارير الحالي محفوظ في التطبيق | Saved datasets / API-ready datasets / drill-downs والتحليلات المتقدمة لم يتم التحقق من اكتمالها |
| Notification Center | غير مضاف كوظيفة كاملة في هذه الحزمة | يحتاج event model وقواعد الإشعار وقنوات/مزودي email/WhatsApp؛ لا تُخترع إعدادات أو أسرار |
| Role-based Dashboard | لوحة Dashboard الحالية محفوظة | تفصيل لوحة مختلفة لكل دور يحتاج تحديد KPIs وصلاحيات ظهور البيانات واعتمادها |
| Data Quality Center | لم يضف مركز كامل | يتطلب قواعد جودة بيانات متفق عليها ومصادر حيّة؛ لا يُنشأ باستخدام قوائم ثابتة |
| Scanner-first | بعض مكونات باركود/QR موجودة | اختبار ماسح فعلي، قواعد التركيز/الاختصارات، واختبارات الماسح والباركود مطلوبة |
| Dependencies/lockfile | package.json موجود | لا يوجد lockfile في هذه النسخة المصدرية؛ هناك حزم غير مستخدمة ظاهريًا (`@google/genai`, `express`, `@types/express`, `dotenv`) لم تُحذف لأن clean install/lockfile غير متاح؛ يلزم تنظيف واعتماد ثم إعادة قفل التبعيات |
| Build/Test | فحص صياغة TS/TSX وفحص الاستيرادات فقط | Vite build وTypeScript typecheck الكامل لم ينجحا/لم يثبتا بسبب التبعيات غير المثبتة |
| Supabase | API/SQL candidate ضمن الحزمة | لم يتم الاتصال بالمشروع الحي؛ schema/Auth/RLS/RPC/Storage/Realtime حالة NOT VERIFIED |

## ما يعنيه هذا الجدول

الحزمة قابلة للمراجعة ورفعها إلى فرع مراجعة في المستودع الصحيح. لا تعني أنها إصدار نهائي للإنتاج أو أن قاعدة البيانات متزامنة. لا تُفعّل أي Migration قبل فحص قاعدة الهدف والنسخة الاحتياطية والموافقة.
