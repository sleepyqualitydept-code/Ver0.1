# استبعاد SQL التاريخي من حزمة التسليم

أزيلت ملفات SQL التاريخية والمتعارضة من حزمة التسليم لتقليل الالتباس ومنع تشغيل أوامر قديمة مثل `DROP ... CASCADE` أو ملفات حذف بيانات. وهي ليست جزءًا من مخطط الإصدار الحالي.

الملفات الثلاثة الوحيدة المرشحة للمراجعة هي الموجودة في `supabase/proposed-migrations/`، وتظل `REVIEW_ONLY`: لا تشغيل تلقائي، ولا تنفيذ على مشروع حي قبل فحص المخطط وأخذ نسخة احتياطية وموافقة منفصلة. ملفات `supabase/verification/` استعلامات قراءة فقط ولا تنشئ مخططًا أو تصلحه.
