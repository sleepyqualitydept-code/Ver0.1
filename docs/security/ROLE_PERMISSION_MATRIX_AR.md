# مصفوفة الأدوار والصلاحيات — مرشح v1.6

تستخدم هذه النسخة أسماء الأدوار السبعة الواردة حرفيًا في SSoT. التحقق على الواجهة دفاع إضافي؛ قاعدة البيانات هي الحكم النهائي. المصفوفة أدناه إعداد تحفظي، ويجب اختبار كل حالة تسجيل دخول على Supabase قبل اعتبار سياسات 003 إنتاجية.

| الدور الرسمي | الواجهات المقترحة | العمليات الرئيسية | المحظورات الأساسية |
|---|---|---|---|
| Administrator | جميع الواجهات | إعدادات النظام، تعيين الأدوار، إدارة البيانات، مراجعة السجلات | لا تعديل مباشر لسجل تفعيل الضمان أو السجل التاريخي؛ RPC فقط |
| Production Manager | لوحة المعلومات، البيانات الأساسية، هندسة التصنيع، الإنتاج، التسلسل، الطباعة، التقارير | إدارة أمر الإنتاج والدفعات والقوالب وفق المسارات | لا تعيين أدوار؛ لا تحرير بيانات السيريال/تاريخ الضمان مباشرة |
| Production Operator | لوحة المعلومات، الإنتاج، التسلسل | تشغيل مراحل الإنتاج وتوليد السيريال من خلال RPC | لا إدارة الأدوار أو تعديل السيريال مباشرة |
| Printing Operator | لوحة المعلومات، الطباعة، مصمم الملصقات | إنشاء أوامر واختيار قالب؛ إدارة انتقالات الأمر غير النهائية عبر RPC | لا تسجيل نجاح طباعة من المتصفح؛ لا تعديل `print_history` |
| Customer Service User | لوحة المعلومات، خدمة العملاء، الاستبدال، التقارير | إنشاء/متابعة التذاكر وطلب الاستبدال ضمن RPC | لا اعتماد نهائي للاستبدال في غياب حسم مالك النظام |
| Warranty Manager | لوحة المعلومات، الضمان، التقارير | إدارة السياسات، تفعيل الضمان وتسجيل أحداثه عبر RPC | لا تعديل مدة أو تاريخ نهاية ضمان قائم |
| Read Only User | لوحة المعلومات، الطباعة، التقارير | عرض ما تسمح به RLS | لا كتابات مباشرة أو إدارة عملاء/ضمان خاص عبر سياسات العميل المقترحة |

## سياسة محافظة
- لا تسمح الواجهة للمستخدم باختيار دوره أثناء التسجيل. كل مستخدم يبدأ بلا دور حتى يعيّنه Administrator بواسطة `admin_set_user_role`.
- لا صلاحيات كتابة مباشرة على `warranty_activations` أو `serial_numbers` أو `serial_history` أو `print_history` أو `replacement_requests` أو `replacement_history` أو `audit_logs`.
- `update_print_job_status_v1` يقبل حالات تشغيل/إيقاف/فشل/إلغاء فقط، ويرفض `printed`.
- تعديل حالات الاستبدال النهائية محجوز حاليًا لـAdministrator إلى أن يعتمد المالك خريطة مسؤوليات رسمية. لم نضف دور Service Manager غير وارد في المرجعية.
- الملفات SQL المقترحة لا تمنح موافقة على التنفيذ؛ اختبارات RLS الفعلية لازمة لكل دور في مشروع تجريبي خالٍ من بيانات العملاء.
